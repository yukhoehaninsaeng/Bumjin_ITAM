새 실행 앱은 [platform/](../platform/)에 있습니다. 실행·계정 생성·Docker·검증 방법은 [platform/README.md](../platform/README.md)를 따릅니다. 기존 Excel 앱을 자동 전환하지 않습니다.

TRD의 Django·PostgreSQL 권고안을 이번 개발 브랜치의 기반으로 채택했습니다. 운영 전환·인력별 권한·원본 정책·미결 업무 정책은 아직 확정·배포하지 않았습니다.

## 검증

- PostgreSQL 16에서 권한·티켓·파일·행 버전·상태·원장 검사·동시 배정·중복 생성 등 23개 테스트 통과.
- 실제 Chromium에서 직원 로그인 → 이미지 paste 업로드 → 새로고침·다운로드 → 관리자 인수·내부 메모·해결 → 직원 해결 확인.
- 직원의 내부 메모 제외와 모바일 가로 넘침을 확인.
- 고정 의존성으로 Docker 이미지 빌드.
- CI에 PostgreSQL 기반 동일 테스트·migration 변경 검사·JavaScript 구문 검사 추가.

기존 backend 회귀 테스트도 실행을 시도했으나, 저장소에 포함되지 않은 원장과 `TEST_WORKBOOK` 환경변수에 의존하는 테스트는 실행하지 못했습니다. 37개 중 16개가 통과했고 21개는 해당 사전 조건 누락으로 오류였습니다. 이 브랜치는 기존 backend 코드를 수정하지 않습니다. 실제 운영 원장으로 검증이 완료됐다고 해석하지 않습니다.

## 운영 배포 전 남은 조건

1. 실제 원장의 UUID·직원·조직·SW·계약·이력 이관 검증.
2. 실제 NAS HTTPS·LDAPS·권한 범위 확인.
3. DB·첨부·설정의 일관 백업·복원 시험.
4. 대량 데이터·동시 사용자 성능 측정.
5. 기존 QR·PDF·운영 업무와 전환·원복 절차 확정.

위 조건을 충족하기 전 기존 NAS 앱 대신 이 앱을 운영 서비스로 교체하지 않습니다.
